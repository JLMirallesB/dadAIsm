# dad·AI·sm — Cabaret Volt·AI·re

Experimento de arte sonoro: chatbots entrenados con manifiestos dadá recrean a Hugo Ball, Tristan Tzara y Richard Huelsenbeck y conversan entre ellos.

**Úsalo en línea:** https://jlmirallesb.github.io/dadAIsm/
